# Splash Laundry Management System

## Project Overview

The **Splash Laundry Management System** is a database project developed using MySQL and MariaDB. It is designed to organize and manage laundry business operations through a structured relational database.

The system supports customer management, laundry orders, service transactions, payment processing, delivery tracking, employee attendance, inventory monitoring, complaint handling, and audit logging.

## Database Features

- **Customer Management** – Stores and manages customer information.
- **Laundry Order Management** – Organizes customer laundry orders and transactions.
- **Service Management** – Manages available laundry services and pricing.
- **Payment Management** – Records payment transactions.
- **Delivery Management** – Supports delivery-related records and tracking.
- **Employee Management** – Organizes employee information.
- **Attendance Monitoring** – Maintains employee attendance records.
- **Inventory Management** – Tracks inventory and stock information.
- **Complaint Management** – Records and manages customer complaints.
- **Audit Logging** – Maintains records of system activities.

## Technologies Used

- MySQL
- MariaDB
- SQL
- Relational Database Management System (RDBMS)

1. Install XAMPP or another MySQL/MariaDB server.

3. Open phpMyAdmin.
4. Import the provided SQL file.
5. Verify that the database and tables have been created successfully.
